## Краткий текстовый отчёт

### Созданные экраны
Было разработано три основных экрана мобильного приложения:

1. **Главный экран (Экран 1)** - стартовый экран приложения с черным фоном, логотипом Spotify в центре и кнопкой "Слушать" в нижней части экрана.

2. **Экран исполнителей (Экран 2)** - содержит две карточки с исполнителями, каждая из которых включает:
   - Название исполнителя
   - Кнопку "Перейти на страницу исполнителя"

3. **Экран плейлиста (Экран 3)** - отображает список музыкальных треков выбранного исполнителя в формате чек-листа, а также кнопку возврата "к списку исполнителей".

### Использованные элементы интерфейса
- **Фреймы**: Три фрейма формата iPhone 14/15 Pro
- **Текстовые элементы**: Заголовки, описания, названия треков
- **Кнопки**: Интерактивные элементы для навигации ("Слушать", "Перейти на страницу исполнителя", "к списку исполнителей")
- **Чек-листы**: Элементы выбора треков с статусами completed/active
- **Визуальные элементы**: Логотип Spotify, разделители, карточки исполнителей

### Организация навигации
Навигация между экранами организована по линейному принципу:
1. С **Главного экрана** по нажатию кнопки "Слушать" осуществляется переход на **Экран исполнителей**
2. С **Экрана исполнителей** возможен переход на **Экран плейлиста** конкретного исполнителя
3. С **Экрана плейлиста** предусмотрена кнопка возврата "к списку исполнителей"

Все переходы анимированы с использованием эффекта "Smart Animate".
