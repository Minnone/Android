Использованные виджеты
Виджеты компоновки:
MaterialApp - корневой виджет Material Design
Column - вертикальное расположение
Row - горизонтальное расположение
Center - выравнивание по центру
Container - декорирование и отступы 

Стили и оформление
Текст:
Красный цвет, размер 24px, жирное начертание
Белый текст на черном фоне
style: TextStyle(
  color: Colors.red,              
  fontSize: 24,                       
  fontWeight: FontWeight.bold,        
)

Контейнеры:
Черный контейнер с черной рамкой
Светло-зеленый контейнер со скругленными углами (15px)
Оранжевый и розовый внутренние блоки

Цветовая схема:
Colors.red - заголовок
Colors.black - основной контейнер
Colors.white - текст на темном фоне
Colors.green[100] - светлый фон
Colors.orange и Colors.pink - акцентные элементы
